# 单机部署边界

状态：2026-10-20 已在阿里云上海 ECS 上完成私有入口部署；公网域名和 HTTPS 尚未接入，ICP备案仍在审核流程中。

## 已运行的结构

生产环境使用 `compose.production.yaml` 管理 PostgreSQL、API 和 Web。PostgreSQL 只在 Docker 私有网络内提供服务并使用独立命名卷；API 也只在私有网络内；Web 仅绑定服务器 `127.0.0.1:18080`。当前没有公网 HTTP/HTTPS 入口。生产环境变量保存在服务器的 `.env.production`，不提交到仓库。

服务器已加载本机验证过的三个镜像，执行到当前 Alembic head，并导入 6 个公共角色、9 个角色版本；新生产库没有迁移本机开发账号、聊天或个人记忆。内部验收中首页、Web 健康检查和 API 健康检查均返回 200，匿名账号接口返回 401；最终域名 `afterstoryai.com` 的 Host 检查返回 200。当前模型仍为 fake，不调用真实 LLM。

已生成 PostgreSQL 自定义格式备份，验证归档目录，并复制到 Windows 后比对 SHA-256。自动定期备份及恢复演练尚未完成；Docker 命名卷本身不是备份。

## 公网开放前的边界

- `afterstoryai.com` 的首次 ICP 备案已通过阿里云初审，当前等待提交管局；工信部短信核验和管局审核尚未完成。备案应关联实际使用的上海 ECS 作为接入资源，不需要对 ECS 再创建一份独立网站备案；正式提交前可在备案详情中核对实例信息。
- 备案通过后再配置 DNS、HTTPS 网关和安全组公网 80/443；网关必须清理不可信客户端提供的转发头，并正确传递真实客户端 IP、Host 与 HTTPS 协议。Web 镜像目前只接收回环入口的流量。
- HTTPS 验收后才用浏览器验证生产 Secure Cookie、登录、邀请码注册及真实客户端 IP 限速。生产账号和邀请码尚未创建。
- 将 `LLM_ACTIVE_MODEL` 从 fake 切换到真实 Provider、配置密钥，以及长期备份策略，均需单独检查。不要将 `.env.production`、备份或私钥提交到 Git。

项目当前仅使用单机 Compose，不引入 Kubernetes 或额外持久化服务。服务器上由用户启动的容器保持运行；测试或维护脚本不得删除生产卷。
