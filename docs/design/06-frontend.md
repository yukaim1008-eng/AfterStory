## 已确认的设计方向

用户对官方形象参考的新稿反馈：“对的，差不多就是这种感觉。”

| 项目 | 当前有效结论 |
| --- | --- |
| 主角色名单 | 娜娜莉、伊洛伊、薄荷三位并列；角色选择不再使用测试角色占位 |
| 聊天构图 | 沿用左侧角色、右侧聊天，约 40:60；角色画面与文字阅读区域分离 |
| 角色主题 | 根据角色人设和真实形象设计，辅助页面跟随当前角色配色 |
| 娜娜莉配色 | 粉白阅读底色、粉黑点缀；已替代第一版深蓝灰与琥珀色方向 |
| 字体与线条 | 沿用 03 版较清爽的中文无衬线与留白方向，减少硬分割线；具体字体与参数待细化 |
| 角色选择 | 鼠标指向时展开预览，点击才切换当前角色与页面主题；去掉小箭头 |
| 封面素材 | 封面独立替换，名字与按钮不固化进图片；同一窗口分别调整聊天与角色选择裁切；保存失败保留调整，原封面不变 |
| 形象依据 | 参考已查阅的娜娜莉官方形象；黑发占位人物不再代表娜娜莉 |

正式产品范围与相处规则引用 [V1 基线](../decisions/0001-v1-baseline.md)：保留跨世界伙伴关系，不展示好感度、关系进度或内部分析，不新增社区、商城、角色创建器。

## 已有页面设计与待细化内容

| 分区 | 已有设计 | 尚待细化 |
| --- | --- | --- |
| 聊天 | 左图右文、粉白主题、底部输入区 | 具体字体参数、发送中/失败状态、语音规划状态 |
| 角色选择 | 悬停角色展开的静态示意，无小箭头 | 过渡效果、键盘/触屏行为、首次进入与继续对话差异 |
| 角色资料 | 人物、基本说明、当前剧情节点和更新入口 | 真实资料、资料页呈现方式、更新确认与防剧透状态 |
| 历史 | 日期列表与对话预览 | 会话列表契约、分页、空白与失败状态 |
| 外观设置 | 角色主题与封面操作的视觉提案 | 入口、封面裁切、保存方式、恢复默认行为 |
| 个人记忆 | 事实/推测区分，纠正与删除入口 | 纠正表单、删除确认、来源信息与失败状态 |

用户已认可整体视觉方向、两项核心交互及三位主角色名单，不能据此把每个控件、生成图的装饰或未讨论行为都标为已确认。“跟随当前角色”开关等仍为待定建议；正式角色选择已确定不展示工程测试占位角色。

角色选择与封面核心交互已确认。本轮已补充三种用途裁切预览、保存成功、恢复默认确认及恢复失败静态稿，等待反馈；比例与具体裁切仍需匹配正式素材。本分区确认后继续伊洛伊、薄荷的独立页面主题及其他必要状态，沿用已确认方向，不重复询问。
