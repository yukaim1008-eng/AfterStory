## 视觉依据

本次改版逐张参考 `frontend/design/GPT设计图稿/` 的首页、角色、回忆和设置四张图；聊天页按用户指定的沉浸式角色空间实现。最终采用统一的角色主题、半透明玻璃层、留白和柔光，而非将参考截图用作背景。早期 [整套稿](../../data/design-preview/full-desktop-review/README.md)、[09 控件修订](../../data/design-preview/full-desktop-review/09-controls-refinement.png)、[三人选择](../../data/design-preview/three-main-characters-selection-v01.png)、[封面操作](../../data/design-preview/cover-refinement-v02.png) 仅保留为历史实现记录。

默认图位于 data/character-assets，是参考官方图片生成的独立插画，不是正式资产或 Canon。data 当前未被整体 Git 忽略，不删除已认可图片。字体为随工程打包的 Noto Sans SC，不依赖运行时 Google Fonts。聊天文字默认 15px，可调 13/18px。

## F1 实现与暂缓

| 分区 | 当前可运行 | 暂缓或待定 |
| --- | --- | --- |
| 聊天 | 完整文字回复、等待、失败重试、输入法保护、草稿、30轮历史分页、刷新恢复 | 流式、语音、正式表达 |
| 角色选择 | 全彩封面、悬停/聚焦展开、点击切换各自会话 | 动态人物、专门移动端设计 |
| 资料 | 配置介绍、联调标识、紧凑剧情信息 | 正式 Canon、更新接口 |
| 历史 | 用户隔离分页、真实时间/旧时间未知、预览、轮数、来源定位、旧版会话恢复及错误状态 | 正式 Canon 更新流程 |
| 设置 | 通用、外观、声音、数据；偏好持久化 | 账号同步 |
| 封面 | JPG/PNG/WebP，最大10 MB；两处位置与缩放；取消、保存、恢复默认 | 更精细拖拽可后续优化 |
| 个人记忆 | 用户主动手动添加或从成功用户消息保存；列表、空白、失败、更正、删除确认、来源定位 | 自动提取、向量检索 |

封面使用 IndexedDB，偏好和草稿使用 localStorage，均按后端用户隔离；聊天存 PostgreSQL。身份由后端注入，不接受前端指定用户。

## 接口与配置

M1 原路由保留，增加 /api 前缀副本。F1 新增幂等 POST /sessions/open、用户隔离 GET /conversations；用户行锁防止并发重复创建默认会话。GET /health 增加用户与能力标识。契约见 [运行说明](../running-frontend.md)。

前端配置位于 frontend/public/characters.json；提示词为独立 JSON，版本不可变。娜娜莉鉴定师伙伴关系沿用基线；另外两位不套用该关系。正式 Canon 与关系待资料收集后确认。

## 验收与下一步

F1 交付时构建类型检查、后端隔离与并发测试、浏览器交互测试和独立身份的真实模型回复/刷新恢复已通过，结果见 [当前状态](../current-status.md)。用户反馈整体流程跑通，当前先整理文档，由用户通过 [选择清单](../next-step-review.md) 决定下一阶段。性格和角色资料库暂缓；语音等聊天效果获用户认可后再做，未启用页面不自动触发对应后端开发。
