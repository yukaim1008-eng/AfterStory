2026-09-16 CharactersPage 角色世界入口：只重设计角色页，不更改既有 Desktop 高度体系、Home/Chat/回忆/设置或业务链路。轻量标题区明确“今天，想和谁说说话？”，单一主体舞台改为左侧当前角色、右侧两位待相见角色；当前角色读取既有 `sceneDecorations.signature` 作为手写短签名，并以“当前角色 / 继续和她聊天”强化正在陪伴的身份。第二轮只精修卡片内部：全幅角色图经透明渐变自然延伸到文字层，主卡和次卡不再硬切为图片与白色资料区；签名用楷体回退栈和轻微旋转，娜娜莉/伊洛伊/薄荷的 hover 分别为暖粉轻抬、最小柔和浮动、青蓝稍活跃浮动。其他角色保留已有封面、名字、短句、主题与 `choose()` 点击行为，作为较弱的“去见她的故事”入口；角色扩展时仅右栏内部滚动，默认三位角色在四档桌面视口同时可见。`CharacterCard.vue` 仅在 CharactersPage 使用，本页局部持有主次比例、轻玻璃表面、hover 与低高度收紧规则；没有新增角色配置字段或改动场景背景、会话、记忆和路由逻辑。

2026-09-16 HomePage 相见入口：只重设计首页，不更改上一阶段 Desktop 高度体系、其他页面或聊天业务。Hero 为一个完整场景容器，默认从当前角色已有 `sceneBackground` 读取横版房间素材，避免竖版封面放入宽区域时过度放大脸部；当前用户保存的个人封面优先使用，并继续读取原聊天裁切。右侧欢迎内容、头像、主次动作以淡玻璃渐变叠入场景，而非独立白色功能卡，不再嵌套 GlassPanel。Home-only 选择器将页面背景表现收为奶白中性色，保留角色 Accent/按钮/图标及轻量字迹；首页 Header 保持结构与 72px 高度，只收短 Active underline。`sceneDecorations.homeGreeting` 为可选字符串，三角色独立配置，缺省“欢迎回来”。最近回忆保留当前实例的合并排序和最多三条，呈现角色小头像、真实时间及用户聊天/Memory 摘要；空态显示小书本、自然引导及原有聊天路由 CTA，不制造大面积空白。四个快捷动作保留路由，其他角色以小头像/名字/短句收拢成可点击入口带，整个条目沿用 choose 切换角色。首页 scoped CSS 独立持有这些表现，不覆盖其他页面。

2026-09-16 Desktop 尺寸收口：暂停所有页面视觉重设计。Home、Characters、Chat、Memories（History/Memory）和 Settings 在桌面窗口统一按 `100dvh` 布局，Header 固定 72px；横向页面留白为 32–48px，纵向留白/区块间距为 20px，视口高度不超过 800px 时收紧为 16px。首页 Hero 和角色卡从固定最低高度改为剩余空间分配，保留模块结构与内容；主要标题控制在 32–42px。消息在 `.messages` 内滚动；回忆的标题、Tabs、筛选固定，分别由 `.history-scroll` 和 `.collection-scroll` 承接内容滚动；设置导航固定，只有 `.settings-panel` 滚动。新增两个无业务逻辑的列表滚动容器，不修改 API、会话、记忆、角色配置、背景、颜色或字体风格。此阶段不代表页面视觉重新设计已完成。

2026-09-15 更新：聊天页旧的“左角色 Card + 右聊天 Card”与 40:60 Grid 规则已废止。当前 ChatPage 是覆盖单个 viewport 的完整 Character Scene，人物不是某一列的内容，而是由绝对定位的环境层、主肖像层和穿入层共同组成；穿入层通过局部 mask 越过 Chat Glass 左缘，玻璃材质位于其下、聊天内容位于其上。页面根层禁止纵向滚动，只有消息列表内部滚动；布局不能再由全局 `.workspace` 或 `style.css` 的聊天选择器决定。本轮只完成聊天页，其他一级页面按后续阶段分别清理。

2026-09-15 聊天页视觉收尾：在不改变场景、玻璃层位置、消息滚动边界或业务链路的前提下，Chat Glass 调整为更轻的透明渐变、10px 局部模糊与低饱和度；角色消息改为署名与轻量引线正文，连续角色消息收拢重复署名，用户消息保留右对齐的低饱和主题色软气泡并限制宽度。输入框保持底部悬浮，使用半透明材质、焦点边框与柔和阴影；空态降低为次级视觉层。浏览器回归以九条模拟消息和空态分别验证单屏、内部滚动、连续角色消息、长用户消息、输入焦点与背景可读性；未向真实业务数据写入测试消息。

| 分区 | 当前可运行 | 暂缓或待定 |
