# 正式角色资料整理入口

状态：第一版候选资料，等待用户集中审核；尚未导入数据库，也未切换任何现有 `CharacterInstance`。

## 本轮范围

本目录整理娜娜莉、伊洛伊、薄荷在公开角色介绍和角色语音中能够确认的稳定信息，并映射到 Minimal Character Schema v1 的六个字段。候选数据位于 `fixtures/companions.profile-v1.candidate.json`，只作为审核和校验输入：

- `identity`：角色身份与稳定背景；
- `personality`：核心性格和价值倾向；
- `speaking_style`：默认称呼和稳定表达习惯；
- `behavior`：基本交流方式、自主立场与互动边界；
- `worldview`：海特洛、异象与跨世界通信的稳定前提；
- `relationship_premise`：用户身份映射和初始关系，不写入后续关系变化。

本轮不整理完整剧情 Canon，不从零散语音推定具体共同事件，不建立 Voice Profile，也不把 Memory、State、Relationship 或 Conversation 写入 Character Definition。

## 来源与证据类型

| 类型 | 含义 | 使用方式 |
| --- | --- | --- |
| 游戏个人档案 | 游戏内公开的身份、档案和语音；信息站属于该内容的搬运来源 | 可以确认档案中明确写出的事实，但官网与搬运页出现同一文本时只算一份内容来源 |
| 游戏剧情录像 | 主线、角色故事、羁遇、都市偕游和活动的实际录屏 | 按场景和时间点记录角色选择、反应与表达，是人物塑造的主要证据 |
| 人物归纳 | 根据多段档案语音或剧情表现形成的判断 | 必须记录触发条件、表现方式、边界和证据引用 |
| 玩家总结 | 评论、攻略或人物分析 | 只用于发现待查线索，不单独证明稳定人设 |
| 用户确认 | 用户根据实际剧情体验确认的人物理解 | 可以先作为暂定判断保存，之后补具体剧情证据 |

候选文本不复制整段官网文案或语音，只记录事实摘要和表达模式。每位角色的来源、已确认信息、推断边界和待审点分别记录在本目录文档中。

面向所有命名角色的资料结构、采集顺序和当前覆盖见 [人物资料研究库](character-corpus.md)。

## 导入边界

审核通过后，仍需执行以下动作才会成为正式可用版本：

1. 根据审核意见修改候选 Definition；
2. 确认每位角色的 `version_id` 与 `checkpoint`；
3. 使用现有 `seed()` 显式导入，由 Prompt Builder v1.0 生成冻结 `system_prompt`；
4. 新建或显式切换实例进行测试。现有实例不会自动升级，旧联调版本继续可用。
