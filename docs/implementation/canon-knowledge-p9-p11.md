## 关键处理与边界

- P10 揭示了 P9 委托人蕾妮的真实身份（康斯坦丁家最年幼的木偶孩子）。P9 按当时认知记录「上门求助的出租车司机」，P10 再记录身份揭示，两处记录并存，不回改前文结论。
- P11 中段（约 371–642 句）几乎没有确认说话者，对应场景以客观概括记录；确无可辨认行为者时 `participants` 留空，不虚构角色归属。
- 梦境、传说与不可靠叙述（蕾妮的身世、康斯坦丁往事、占卜、洄廊与「游梦人」、娜娜莉的自我怀疑）一律按 `reported_claim` / `character_belief` 或带 `limitations` 保存，不断言为客观事实。
- 非角色的命名对象（如「莳」「小贞」）以世界实体承载；被提及但不在角色目录、且证据不足以绑定人物的名字（特蕾莎、埃略特）不强行登记。
- 原作人物关系仍不进入现实用户与角色实例的 Runtime Relationship。
