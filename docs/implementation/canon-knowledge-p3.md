# Canon K4：P3《番外 月光当铺》剧情、知识与人物证据

状态：完成。

## 本阶段范围

本阶段只处理 `BV1kqoaBiEVZ` P3《番外 月光当铺》。视频经本地 GPU OCR、低成本两级模型审核、少量高能力复核后，提升为正式 Scene、Canon Evidence、人物/世界/关系知识和人物表现证据。没有处理 P4，没有写入生产 PostgreSQL、Character Definition、CharacterInstance 或聊天运行时。

低成本流程生成 27 个有界审核包，输入约 348,753 字符，其中 522 条需要查看画面、165 条走纯文本路径。第一轮自动接受 339 条；第二轮轻量模型复核后共有 646 条进入自动路径，余下 41 条交给高能力模型逐项看图，最终 34 条通过、7 条拒绝。`low-cost-finalize` 只在全部高审条目有明确决定后生成正式审核稿。

人物消歧复核修正了两个易错点：漫画作者「蛋烘糕扫荡」与寻找爱犬的「嘭嘭」是不同人物；「蒲公英」是墨菲克斯的别名，不重复建立人物节点。凯尼斯当票中出现的感官与年限冲突没有被静默统一，正式知识只保留剧情能够稳定支持的“失去味觉”，不确定组合继续留在来源证据中。

## 时间与模型使用

可独立计时的本地步骤为：下载 12 分 27.7 秒、GPU OCR 8 分 55.5 秒、审核帧与联络表 56.2 秒，共 22 分 19.4 秒。第一轮轻量模型审核耗时 28 分 16.8 秒；之后因 Codex 额度暂停，第二轮与知识整理的跨暂停总墙钟时间不再具有可比性。

本次共执行 33 次轻量模型任务和 3 次高能力模型任务。33 次轻量任务包含 3 次被严格 Schema 拒绝的早期响应、第二轮疑难复核以及场景计划修正；高能力模型只用于 41 条残余视觉疑难和最终知识抽取。项目的聊天 Provider 和真实 LLM API 均未调用。
