# F1 可替换参考封面

2026-09-12 使用内置 imagegen，分别参考 data/design-reference 中的官方娜娜莉、伊洛伊白外套默认造型、薄荷生成三张独立竖幅插画。它们是运行预览素材，不是正式资产或 Canon，不替代已认可设计稿。

nanally.png、iroi.png、mint.png 是默认源图；名字、按钮与资料由页面绘制。更换源图后运行 frontend 下的 npm run prepare:media；用户可以在设置中单独换图。

生成要求：保留参考形象特征，胸腰部肖像、面向观众；娜娜莉粉色图形背景，伊洛伊浅绿植物/淡紫，薄荷青绿/少量黄；无文字、Logo、界面、边框。后续可替换更贴合性格的正式素材。
