## 行为说明（上述两项已确认，其余为细化建议）

| 场景 | 行为与输出 |
| --- | --- |
| 打开角色选择 | 默认展开当前角色，其他角色收窄；没有当前角色时默认预览首个可用角色，不自动创建实例 |
| 悬停另一角色 | 卡片原顺序不变，仅重新分配宽度；不改变当前角色、对话或全站主题 |
| 离开卡片区域 | 回到当前角色的默认展开状态；避免进入卡片内按钮时误触恢复 |
| 点击角色或文字按钮 | 进入该角色对话后切换当前角色及主题；既有对话如何发现和恢复待接口补齐 |
| 键盘操作 | 聚焦时显示同等预览，Enter/Space 激活；显示清楚的聚焦边界；静态稿尚未逐项覆盖 |
| 更换封面 | 从设置的外观入口选择本地图片，进入草稿预览，不立即覆盖原图；文件类型、大小等限制随保存方案确定 |
| 调整裁切 | 同一源图，聊天封面和角色选择封面分别调整位置/缩放，并同时看到用途预览；名字与按钮独立排版 |
| 取消 | 放弃本次草稿，原封面保持不变；不修改角色资料、主题或对话 |
| 保存中 | 保留预览，按钮显示保存中并阻止重复提交；未成功前不把新封面当成已保存 |
| 保存成功 | 关闭调整窗口并轻提示“封面已更新”，两个使用场景应用已保存的对应裁切 |
| 保存失败 | 留在调整窗口，保留草稿和原封面；显示错误与重试保存，不要求重新选图 |

建议动画初值约 240ms，仅改变卡片布局与裁切，不用大幅缩放整个页面；用户系统要求减少动态效果时直接切换。该时长尚未实现或验收。

## 画面检查与待定

- 本稿能比较默认/悬停布局及编辑/失败状态，但不代表真实动画已验证。
- 原图预览偏矮，已在 [封面操作细化](cover-refinement.md) 中补充聊天、展开、收窄三种画幅预览。真实比例、面部与耳部留白仍需结合正式素材校正，旧缩略图比例不作为规范。
- 封面操作放在“设置 → 外观”、对当前用户角色实例生效，是本轮建议；用户尚未确认作用范围和保存位置。后端暂无上传、裁切配置与持久化契约。
- “重置位置”只重置当前裁切草稿，“恢复默认封面”属于另一操作；成功提示、恢复默认确认及失败已在封面细稿中展示，行为待反馈。
- 文件不支持、加载失败与触屏等状态尚未逐项出图，本分区未全部验收。
