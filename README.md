# AfterStory

AfterStory 是以长期角色陪伴为核心、采用跨世界交流设定的 Web 应用。V1 主角色为《异环》的娜娜莉、伊洛伊、薄荷，三位并列；范围以决策基线为准。

M1 文字后端、F1 前端与 F2 五阶段基础能力已实现。真实模型回复、持久化和刷新恢复已做联调；历史、用户主动管理的个人记忆、受限上下文、内部状态边界及本地诊断已经接通。语音、自动记忆/状态策略和正式角色资料仍未完成，完整 V1 未验收。

当前适合由用户运行整套页面，继续评估聊天与管理体验；暂不调整性格或建设角色资料库。语音等用户认可聊天效果后再推进。
