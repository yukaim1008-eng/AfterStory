# AfterStory

AfterStory 是以长期角色陪伴为核心、采用跨世界交流设定的 Web 应用。V1 主角色为《异环》的娜娜莉、伊洛伊、薄荷，三位并列；范围以决策基线为准。

M1 文字后端与 F1 前端已实现，真实模型回复、持久化和刷新恢复已做联调，用户反馈整体流程已跑通。长期记忆、关系状态与语音尚未接入，完整 V1 未验收。

当前整理已确认规则、实现边界与候选工作，由用户决定下一阶段；暂不调整性格或建设角色资料库。语音等用户认可聊天效果后再推进。
